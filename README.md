# yumeen.com

A simple static site scaffold.

## Structure

- `index.html` — main page
- `css/style.css` — styles
- `js/main.js` — scripts
- `images/` — image assets

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
